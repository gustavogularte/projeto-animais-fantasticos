# 📖 Sobre

O **Animais Fantásticos** é um projeto desenvolvido durante o curso **JavaScript Completo** da Origamid com o objetivo de colocar em prática conceitos fundamentais de JavaScript moderno através da construção de uma interface dinâmica e interativa.

Durante o desenvolvimento foram implementadas diversas funcionalidades utilizando **JavaScript puro**, organizadas em módulos e classes, tornando o projeto uma excelente prática de manipulação do DOM, eventos e programação orientada a objetos.

---

# ✨ Funcionalidades

O projeto conta com diversas funcionalidades desenvolvidas ao longo do curso, entre elas:

- 🖼️ Slide de imagens interativo
- 📱 Menu Mobile
- 📑 Navegação suave (Smooth Scroll)
- 🎯 Navegação por Tab
- ❓ FAQ com Accordion
- 🪟 Modal
- 🖱️ Tooltip
- 🎬 Animações ao Scroll
- ⏱️ Indicador de funcionamento da ONG em tempo real
- 📊 Contador animado de números
- 🌐 Consumo de dados externos utilizando Fetch API
- ⚡ Manipulação do DOM com JavaScript puro
- 📦 Organização do código utilizando ES Modules
- 🏗️ Programação Orientada a Objetos (Classes)
